# daily-insp

Consciouslab Daily Insp görselleri. Her hafta içi `YYYY-MM-DD/` klasörüne yazılır:

- `{font,brand,web}_N.png` — Google Chat kartının tıklanabilir dilimleri (0 = hero, 1..n = satırlar, son = footer)
- `_full_{font,brand,web}.png` — kategori kartının tamamı

Chat'e `raw.githubusercontent.com/necatiarc/daily-insp/<commit>/...` linkiyle verilir.
